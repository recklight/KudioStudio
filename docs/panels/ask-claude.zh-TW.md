# Claude

其他面板負責量測，這個面板把量到的結果用文字講給你聽。「問 Claude」會透過 Anthropic 的 API
把這段音訊的數據送給 Claude，再把 Claude 的解讀顯示出來：一段整體說明、依重要性排列的發現，
以及下一步該做什麼，每一步都寫明由哪個面板來做，並附上開啟那個面板的按鈕。

它讀的是數字，不是錄音本身，也可能說錯。請把它的發現當成對數字的解讀，再用耳朵聽、
用量出那個數字的面板確認。

## 送出的內容 {#what-is-sent}

Claude 能讀文字和圖片，不能聽音訊，所以錄音本身從來不會送出去。按下去之前，面板就會列出要送的東西：

- 長度、取樣率、聲道數，以及開啟後有沒有編輯過
- 峰值、true peak、RMS、響度與響度範圍
- 底噪、估計 SNR、頻寬、削波樣本數、DC 偏移、靜音所占的比例，以及非有限值樣本的數量
- kudio 對這段錄音找到的問題，用它自己的話
- [指標](metrics.md)面板的表格，前提是那張表是在目前這版音訊上量的

檔名和路徑都不會一起送出。這份清單會跟著音訊走：編輯之後會重新量測，而編輯之前做的指標表格
就不再送出，因為它量的已經不是這段音訊。音訊在回答之後改過的話，回答上方會註明。

## 你的金鑰 {#your-key}

這個面板用的是你自己的 API 金鑰。在「編輯 → 設定…」的「Claude」底下，「取得金鑰…」會在瀏覽器
開啟 Claude Console，金鑰就在那裡建立。把金鑰貼進「API 金鑰」，按「儲存金鑰」再按「測試」。
「測試」會列出這把金鑰能用的模型並說明有幾個，不花任何費用。

金鑰存在系統的認證管理員裡（Windows 的認證管理員、macOS 的鑰匙圈），不在 KudioStudio 的設定檔中，
設定視窗只顯示它的最後四個字元。如果 `ANTHROPIC_API_KEY` 環境變數裡已經有金鑰，或用過
`ant auth login`，不用另外儲存就能用。「移除金鑰」會把存起來的那把從認證管理員刪掉。

每次提問都會計入那把金鑰所屬帳戶的費用。回答下方那一行會寫出這次用了多少 token；對於
KudioStudio 有價格資料的模型，也會寫出大約花了多少錢。Claude Sonnet 5.5 的價格是每百萬 token
輸入 2 美元、輸出 10 美元。

## 用哪個模型 {#which-model}

設定裡的「模型」在你改選之前都是「自動」，而在這一版裡，「自動」就是 Claude Sonnet 5.5，
也就是這些回答實際試過的模型。之後的 KudioStudio 可能把它換成更新的模型，「自動」也會跟著換。

按過「測試」之後，清單裡還會列出這把金鑰能用、而且能照這個面板讀取的固定格式回答的每一個模型，
清單來自 Anthropic 的模型清單 API。比這一版 KudioStudio 更晚推出的模型，也能直接在那裡選，
不用等 KudioStudio 更新。

選了的模型如果之後被停用，並不會卡住。面板會改問「自動」對應的模型，說明是哪個模型停用了，
並把選擇改回「自動」。

## 沒有回答的時候 {#when-there-is-no-answer}

| 狀態列寫著 | 意思 |
|---|---|
| 還沒有 API 金鑰。到「編輯 → 設定…」加上你的金鑰。 | 沒有存金鑰、環境變數裡也沒有，而且「測試」也沒找到 |
| API 金鑰被拒絕，或是沒有金鑰。 | 金鑰打錯或已被撤銷；到 Console 建一把新的 |
| 這把金鑰不能使用 ‹模型›。 | 金鑰所屬的組織不能用那個模型；改選別的，或改回「自動」 |
| 這把金鑰的帳戶已經沒有額度了。 | 帳戶需要到 Console 加值 |
| 目前請求太多，請 ‹n› 秒後再試。 | 這把金鑰的速率限制；等待時間由 Anthropic 決定 |
| 連不上 Anthropic API。 | 電腦沒有連網，或防火牆擋住了 api.anthropic.com |
| Claude 拒絕回答（‹類別›）。 | Anthropic 的安全分類器擋下了回答。用 Claude Sonnet 5.5 時，這個問題已經改用 Anthropic 針對這種情況推薦的模型試過一次 |
| 回答超過長度上限，被截斷了。 | 回答比面板允許的還長；再問一次 |
| 要問 Claude 需要 anthropic 套件：… | KudioStudio 安裝時沒有連同相依套件一起裝；照那一行寫的把兩個套件裝上 |
